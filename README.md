# Entertainment Guarantors theme

WordPress theme for Entertainment Guarantors Malta, rebuilt from the archived Wix site.

1. Install the ZIP from the latest release (or update from Appearance > Themes) and activate it.
2. Click **Complete Entertainment Guarantors setup** in wp-admin. It sets permalinks to /%postname%, the site title, imports the images into the Media Library, then creates the editable pages Home, Services (/solutions), Our Team and Partners (/about) and Contact (/contact), sets Home as the homepage and creates the Main menu.

Editing: Pages (block editor; the pages use the "Designed page (full width)" template), Appearance > Menus, Appearance > Customize > Footer contacts / Site Identity (logo), Settings > General (contact form recipient). Enquiries are saved under Enquiries.
